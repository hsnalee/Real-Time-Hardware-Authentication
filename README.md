# Real-Time Authentication of Embedded Hardware

**Official repository for the research paper "Real-Time Authentication of Embedded Hardware" — EAI SMARTSP 2026.**

This repository accompanies our research on physical-layer device fingerprinting for real-time identification and authentication of embedded hardware.

Our proposed framework utilizes **Plateau-Residual Spectrograms (PRS)** and a **Convolutional Neural Network (CNN)** to extract device-specific electrical characteristics from switched-voltage signals. Open-set rejection enables the framework to distinguish enrolled devices from unknown hardware.

### Key Highlights

- **15 embedded devices** across five hardware families.
- **94.78%** mean cross-session identification accuracy using PRS.
- **0.00% FAR and FRR** in the evaluated real-time authentication experiments.
- **96.7%** enrolled-device identification accuracy.
- **0.830 seconds** median end-to-end authentication latency.
